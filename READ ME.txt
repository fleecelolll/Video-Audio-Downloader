VIDEO + AUDIO DOWNLOADER

A little tool I made with AI to download videos and audio from yt-dlp-supported sites locally on 64-bit Windows.

INSTALL

1. Download the latest release ZIP.
2. Extract the complete folder.
3. Double-click Installer.bat.
4. Press Y once to accept the Terms and bundled Tool License and approve setup.
5. Leave the setup window open until every check passes.
6. Double-click the Video + Audio Downloader shortcut created in the folder.

Keep the full extracted folder path at 72 characters or fewer so Windows can install the private packages reliably.

USE

1. Paste a supported URL.
2. Select MP4 or MP3.
3. Choose the quality and save folder.
4. Click Download.
5. Leave the app open until download and conversion finish.

SETUP DETAILS

Setup keeps official Python 3.14.7, PySide6-Essentials, yt-dlp, yt-dlp-ejs, FFmpeg, FFprobe, Deno, settings, and app-specific files private to this folder. It does not require administrator access, change PATH, or install global Python packages. Downloaded runtime archives are verified before use.

Setup creates and validates a folder-local Video + Audio Downloader shortcut that starts the app directly with this folder's private runtime. Run Installer.bat again to repair setup or after moving the complete folder. The selected save folder, format, and quality are preserved.

PRIVACY AND REMOVAL

The app has no telemetry, analytics, advertisements, or app accounts. Network requests occur only for setup and the downloads you start. Review logs before sharing because they can contain media URLs and local folder paths.

To remove this tool, close it and delete the extracted folder. This removes its folder-local shortcut, private runtime, dependencies, settings, logs, and app files.

TROUBLESHOOTING

If setup or the shortcut fails, review setup.log and run Installer.bat again. Success is shown only after the dependencies, offline self-tests, and shortcut all pass. Keep the complete extracted folder together.

Before downloading Python or other large components, setup checks the bundled app source, Windows ZIP extraction, and shortcut support. If one of these fails, the setup window shows a short "How to fix" instruction immediately. A failed Python, package, FFmpeg, or Deno step also stops at that step and gives a targeted repair hint rather than waiting until the end.

If setup says the app source is missing or unsafe, re-extract the complete official ZIP. If it says ZIP extraction is unavailable, repair Windows PowerShell or its Microsoft.PowerShell.Archive module. If shortcut creation fails, check for a broken existing shortcut or folder write access. Download-stage errors should be diagnosed using the last error in setup.log; no downloaded runtime is accepted unless its SHA-256 check passes.

If one site stops working, run the latest Installer.bat to refresh the pinned downloader components before retrying.
